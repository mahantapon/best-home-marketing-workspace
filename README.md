# best home — Marketing Workspace

เว็บจัดลำดับงานและวางแผนทีม Marketing ของ best home จากแผนเสนอวันที่ 12 พฤศจิกายน 2569

## สิ่งที่ทำได้

- ภาพรวมงาน 59 รายการ แบ่ง A 8 / B 12 / C 31 / D 8
- หน้า Dashboard พร้อมการ์ดสรุปสีพาสเทลและตัวนับสถานะจริง
- การ์ดงานเป็นมุมมองหลัก สลับเป็นตารางได้ พร้อมค้นหา/กรองผู้รับผิดชอบและสถานะ
- บอร์ด A–D แบบ 2×2 แสดง 3 งานแรกของแต่ละกลุ่ม และเปิดดูทั้งหมดได้
- แก้กลุ่ม ลำดับ ผู้รับผิดชอบ สถานะ วันส่ง และบันทึกเพิ่มเติม
- บทบาททีมและแผนพัฒนาทักษะ 4 สัปดาห์
- ประวัติงานเดิมอีก 16 รายการ แยกจากรายการจัดคิว
- ส่งออก CSV และสำรอง/นำเข้าการแก้ไขเป็น JSON
- พิมพ์มุมมองปัจจุบัน รองรับมือถือและคีย์บอร์ด

รายการเป็นข้อเสนอจัดลำดับ ไม่ใช่การยืนยันว่าทุกงานยังค้างอยู่ กำหนดส่งจริงเริ่มต้นเว้นว่างไว้

## ใช้งานในเครื่อง

เปิดไฟล์ `preview.html` ด้วยเบราว์เซอร์ได้ทันที ไฟล์นี้รวมหน้าเว็บและข้อมูลไว้ในไฟล์เดียว (สร้างใหม่ด้วย `npm run build` หลังแก้โค้ด)

สำหรับพัฒนาและรันผ่าน local server:

ใช้ Node.js 20.11 ขึ้นไป ไม่ต้องติดตั้ง dependencies

```sh
npm run dev
```

เปิด URL ที่คำสั่งแสดง (ค่าเริ่มต้น `http://127.0.0.1:4173`)

```sh
npm test
npm run build
```

ไฟล์สำหรับโฮสต์อยู่ใน `dist/` ใช้ลิงก์แบบ relative จึงรองรับโฮสต์ใน subdirectory ได้

## ข้อมูลและการบันทึก

ข้อมูลตั้งต้นอยู่ใน `data.js` การแก้ไขเก็บใน **localStorage ของเบราว์เซอร์นั้น** ไม่มี backend และไม่มีการซิงก์ระหว่างผู้ใช้หรือเครื่อง เมื่อเปลี่ยนเครื่องให้ส่งออก JSON แล้วนำเข้าในเครื่องใหม่

สถานะเริ่มต้นคือ “รอตรวจสถานะ” งานที่ปักโฟกัสไว้คือ A1–A8, C1 และ C2 กรองโฟกัสจะไม่รวมงานเสร็จแล้วหรือพักไว้

เนื้อหาเป็นแผนงานภายในบริษัท แนะนำให้ใช้ repository ส่วนตัว การทำให้ repository หรือหน้าเว็บสาธารณะต้องพิจารณาผู้เข้าถึงแยกต่างหาก
