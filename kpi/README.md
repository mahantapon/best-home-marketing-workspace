# best home — ตารางประเมิน KPI ทีมคอนเทนต์

หน้าเว็บเพิ่มเติมสำหรับ Marketing Workspace จัดทำวันที่ 16 พฤศจิกายน 2569

## การใช้งาน

- เปิด `kpi/` บนเว็บ GitHub Pages เดิม เลือกรอบประเมิน กรอกชื่อและวันเริ่ม/สิ้นสุด
- กรอกจำนวนที่ทำได้และจำนวนทั้งหมดในแต่ละด้าน ระบบคำนวณผลจริงและคะแนนถ่วงน้ำหนักให้ทันที
- ช่วงแรกเลือกโหมดเก็บข้อมูลฐาน เป้าและน้ำหนักเป็นข้อเสนอทดลอง ปรับได้ก่อนใช้ประเมินจริง
- ช่องว่างคือรอข้อมูล ส่วน 0 คือผลงานจริงที่เป็นศูนย์ ไม่มีงานให้วัดเลือก N/A และดูน้ำหนักที่มีข้อมูลประกอบคะแนน
- เพิ่มงานและสถานะในแผนรายสัปดาห์เพื่อประกอบการประเมิน ตัวเลขไม่ถูกคัดลอกไปเป็นคะแนนโดยอัตโนมัติ
- ส่งออก CSV สำหรับเปิดในตารางคำนวณ ส่งออก/นำเข้า JSON เพื่อสำรองและย้ายเครื่อง หรือพิมพ์/บันทึกเป็น PDF
- ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ ไม่มีบริการรับผลประเมิน ไม่ซิงก์ข้ามเครื่องและไม่อัปโหลดผลขึ้น GitHub ผู้ที่เปิดลิงก์เห็นแบบฟอร์มว่างของตนเอง
- ไม่มีคะแนนผ่าน/ไม่ผ่านสำเร็จรูป และไม่บวกคะแนนเกินน้ำหนักเมื่อทำได้มากกว่าเป้า

## ตรวจสูตร

ใช้ Node.js รุ่นที่รองรับ node:test:

```sh
node --test kpi/core.test.mjs
```

ใช้ฟอนต์ LINE Seed Sans TH จาก `../assets/fonts/` พร้อมใบอนุญาตเดิมของเว็บไซต์

แหล่งหลักการและวันที่อยู่ในหน้าเกณฑ์และวิธีใช้ ตัวเลขน้ำหนักและเป้าหมายไม่ได้เป็นเกณฑ์จาก CIPD
